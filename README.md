# 2.4 Recruit Ready developer site

Static GitHub Pages site for Winslo Consulting / 2.4 Recruit Ready.

## Required GitHub repository

Create a **public** repository named exactly:

`jameswc-work.github.io`

Upload the files in this folder to the repository root.

Then enable GitHub Pages under **Settings > Pages > Build and deployment > Deploy from a branch**, using the `main` branch and `/(root)` folder.

Expected URLs:

- Developer website: `https://jameswc-work.github.io/`
- Privacy policy: `https://jameswc-work.github.io/privacy.html`
- AdMob app-ads.txt: `https://jameswc-work.github.io/app-ads.txt`
